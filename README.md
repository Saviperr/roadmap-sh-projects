# Server Stats Analytics Script

A lightweight Bash script designed to provide a quick overview of Linux server performance metrics.

## 🚀 Features
- **CPU Usage:** Total percentage of CPU currently in use.
- **Memory Stats:** Breakdown of Used vs. Free memory including percentage.
- **Disk Stats:** Total disk usage, free space, and capacity percentage.
- **Process Monitoring:** - Top 5 processes by CPU consumption.
    - Top 5 processes by Memory consumption.

## 📋 Prerequisites
- A Linux-based environment (Ubuntu, CentOS, Debian, etc.)
- Bash shell
- Standard tools: `awk`, `grep`, `ps`, `top`, `free` (pre-installed on most distros).
